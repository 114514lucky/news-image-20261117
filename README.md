a tanker hit in the Strait of Hormuz as the US strikes an IRGC site
in Iran, a global market sell-off, Ukraine's 1,300-drone barrage on
the Crimea bridge, five EU states planning a Rwanda return hub, US
air-travel and network outages, and the COP31 draft calling for a
faster exit from fossil fuels. Plus a ticker with Trump on Huang and
Kim, Japan scrambling jets, and Amazon losing 40 satellites.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only, no network) draws the
1024x1024 PNG itself with a built-in 5x7 bitmap font and writes it to
`/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). It is fully
deterministic: two runs write identical bytes, in about 5 seconds.
